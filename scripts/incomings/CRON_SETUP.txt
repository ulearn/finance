CRONTAB SETUP FOR DAILY INCOMING PAYMENTS RECONCILIATION
==========================================================

To set up automated daily reconciliation at 6:00 AM:

1. Edit your crontab:
   crontab -e

2. Add this line:

   # Daily incoming payments reconciliation (6am)
   0 6 * * * /home/hub/public_html/fins/scripts/incomings/run-daily-recon.sh

3. Save and exit

WHAT IT DOES:
- Runs every day at 6:00 AM
- Pulls unreconciled credit transactions from Xero bank feed
- Matches payments to HubSpot deals and Fidelo bookings
- Creates payments in Fidelo (when matches found)
- Sends Slack notifications to #financial channel
- Logs all activity to: scripts/incomings/logs/daily-recon-YYYY-MM-DD.log

IMPORTANT NOTES:
- Script is currently in DRY RUN mode (no payments created)
- To enable actual payment creation, uncomment line in run-daily-recon.sh:
  export DRY_RUN=false
- Requires Xero credentials in environment (XERO_EMAIL, XERO_PASSWORD, XERO_TOTP_SECRET)
- Requires HubSpot API key (HUBSPOT_API_KEY)
- Requires Fidelo credentials (FIDELO_EMAIL, FIDELO_PASSWORD)
- Requires Slack webhook URL (SLACK_WEBHOOK_URL)

MANUAL RUN:
To run the reconciliation immediately (for testing):

cd /home/hub/public_html/fins/scripts/incomings
./run-daily-recon.sh

VIEW LOGS:
tail -f logs/daily-recon-$(date +%Y-%m-%d).log
